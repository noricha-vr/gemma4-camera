# Gemma4 Camera

Gemma 4 をオンデバイスで動作させ、カメラ映像をリアルタイム解析して説明文を生成する Android アプリ。完全オフラインで動作。

## 特徴

- カメラ映像のリアルタイム解析
- Gemma 4 E2B によるオンデバイス画像認識（API 不要）
- 生成テキストの画面オーバーレイ表示
- Android TTS による日本語音声読み上げ
- インターネット接続不要（完全オフライン動作）

## アーキテクチャ

```
CameraX (フレーム取得)
    ↓
Gemma 4 E2B (オンデバイス推論)
    ↓
テキスト表示 + TTS 読み上げ
```

### 技術スタック

| 技術 | 用途 |
|------|------|
| Kotlin | 言語 |
| Jetpack Compose | UI |
| CameraX | カメラ制御 |
| MediaPipe GenAI Tasks | オンデバイス LLM 推論 |
| Android TTS | 音声合成（組み込み） |

### モデル

| 項目 | 値 |
|------|-----|
| モデル | Gemma 4 E2B |
| 有効パラメータ | 2.3B |
| 量子化 | INT4 |
| サイズ | ~1.5GB |
| 入力 | 画像 + テキスト |
| 出力 | テキスト |

## 動作要件

- Android 8.0+ (API 26+)
- RAM: 4GB 以上推奨
- ストレージ: ~2GB（モデル含む）
- カメラ搭載デバイス

## セットアップ

### 1. リポジトリのクローン

```bash
git clone https://github.com/noricha-vr/gemma4-camera.git
cd gemma4-camera
```

### 2. モデルの準備

初回起動時にモデルのダウンロードが必要です。

**方法 A: アプリ内ダウンロード（推奨）**

アプリ初回起動時にダウンロードダイアログが表示されます。

**方法 B: 手動配置**

```bash
# Hugging Face からダウンロード
# litert-community/gemma-4-E2B-it-litert-lm
# ダウンロードしたモデルファイルをデバイスの所定のディレクトリに配置
```

### 3. ビルド

```bash
./gradlew assembleRelease
```

## 使い方

1. アプリを起動
2. カメラの使用を許可
3. 「解析」ボタンをタップ → カメラ映像の説明が生成される
4. 「自動」ボタンで 5 秒間隔の自動解析モード
5. 生成されたテキストは TTS で自動読み上げ
